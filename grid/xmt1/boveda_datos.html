⚠️ No borrar este documento

Este documento no tiene interfaz ni funcionalidad propia.
Su único propósito es existir en Grid para tener un docId estable donde viven los state buckets (historial de capturas, catálogos, cola de sincronización) de las auditorías XMT1 (captura_auditoria.html y consolidado_auditoria.html).

Si este documento se borra, se pierde el historial completo de auditorías de XMT1 (Pre-Missort, Inbound/Drivers, Barredura) — de forma permanente, sin posibilidad de recuperación desde las apps.

La app visible (el formulario de captura y el dashboard) puede borrarse y volver a subirse sin problema: apuntan a este documento por su docId, no dependen de dónde vivan ellas mismas.
