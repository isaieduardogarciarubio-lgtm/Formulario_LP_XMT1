⚠️ No borrar este documento

Este documento no tiene interfaz ni funcionalidad propia.
Su único propósito es existir en Grid para tener un docId estable donde viven el Dataset Definition de BigQuery (estatus_envio_lookup) y el State bucket de guardado (estatus_envio_log) de la app de prueba consulta_estatus_envio.html.

Si este documento se borra, se pierde el log de consultas guardadas y la definición del Dataset BigQuery — de forma permanente, sin posibilidad de recuperación desde la app.

La app visible (el formulario de escaneo) puede borrarse y volver a subirse sin problema: apunta a este documento por su docId, no depende de dónde viva ella misma.

Puesta en marcha (una sola vez)

  1. Subir este documento a Grid y copiar su docId (visible en la URL, /d/<doc_id>).
  2. Abrir consulta_estatus_envio.html con ?data_doc_id=<doc_id> en la URL, o reemplazar la constante DATA_DOC_ID dentro del archivo por ese mismo valor.
  3. El usuario que abra la app por primera vez debe tener rol editor (u owner) sobre este documento — el flujo de BigQuery (grid_sql) crea/actualiza el Dataset Definition y dispara refresh, y ambas operaciones requieren permiso de escritura.
